# نموذج البيانات

المخطط الكامل في `src-tauri/migrations/001_initial.sql`. الأموال تحفظ في أعمدة INTEGER باسم `*_minor`، حيث تساوي 1 LYD = 1000 minor units. الفواتير لا تحذف؛ الإلغاء يحفظ المستخدم والوقت والسبب.

البيع الذري ينشئ الفاتورة وبنودها ودفعاتها وحركات المخزون وحركة حساب العميل في transaction واحدة. تكلفة الشراء تُنسخ إلى `sale_items.purchase_cost_at_sale_minor` حتى تبقى الأرباح التاريخية صحيحة.

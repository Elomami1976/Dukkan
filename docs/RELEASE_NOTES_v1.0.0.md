# Dukkan v1.0.0

أول إصدار رسمي من Dukkan، نظام إدارة الأعمال المحلي المصمم لأصحاب الأعمال في ليبيا.

## يتضمن هذا الإصدار

- نقطة بيع للمبيعات النقدية والآجلة.
- إدارة المنتجات والمخزون وحركات التسوية.
- إدارة العملاء والديون والموردين والمشتريات والمصروفات.
- تقارير تشغيلية ومركز مساعدة عربي يعمل دون اتصال.
- حفظ محلي للبيانات مع Backup وRestore بصيغة JSON.
- Windows Installer بصيغة NSIS لمستخدمي Windows 10 وWindows 11 بنواة 64-bit.

## متطلبات النظام

- Windows 10 أو Windows 11، 64-bit.
- لا يحتاج المستخدم إلى Node.js أو Rust أو Git أو Terminal.
- يعمل التطبيق محلياً دون اتصال دائم بالإنترنت.

## الاعتمادية

تم بناء الحزمة واختبار تثبيتها وتشغيلها على بيئة Windows نظيفة عبر GitHub Actions قبل نشر هذا الإصدار.

# Dukkan 1.0.0 — تحديث الفواتير وتبديل المستخدم

رقم البرنامج: **1.0.0**. وسم هذه الحزمة: **v1.0.0-build-3**.

- قالب طباعة فاتورة بالعربية والإنجليزية، مع العربية بحجم أكبر والإنجليزية بلون أخف.
- فصل بيانات المحل والعميل عن جدول الأصناف، وإظهار ملخص الخصم والمدفوع والمتبقي.
- إضافة توقيع البائع والمستلم وعبارة «شكرا لإختيــــــــاركم لنا...».
- زر واضح لتبديل المستخدم دون إغلاق البرنامج، مع اختيار حساب نشط وإدخال كلمة مروره.
- تنبيه قبل التبديل إلى أن التعديلات والفواتير غير المحفوظة ستُغلق.

## التثبيت

نزّل `Dukkan-Setup-1.0.0.exe` من هذا الإصدار. قبل تحديث نسخة مستخدمة، احفظ نسخة احتياطية من داخل إعدادات البرنامج، ثم أغلقه وشغّل المثبت.

إذا ظهرت رسالة «قام Windows بحماية الكمبيوتر»، تأكد أنك حمّلت البرنامج من مستودعنا الرسمي، ثم اضغط **More info (مزيد من المعلومات)** وبعدها **Run anyway (تشغيل على أي حال)** إن كان الخيار متاحاً. هذه الخطوات تخص تحذير التطبيق غير المعروف ولا تنطبق على تنبيه اكتشاف فيروس. البرنامج غير موقّع رقمياً حالياً.

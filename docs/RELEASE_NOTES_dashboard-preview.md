# Dukkan v1.1.0

إصدار كبير يركز على سلامة المخزون، سهولة الاستخدام والعمل المحلي المستمر دون إنترنت.

## تحديث لوحة النشاط والموقع — 27 أكتوبر 2026

- تصميم زجاجي عربي مع مؤشرات المبيعات والتكلفة التاريخية ومجمل وصافي الربح والمصروفات والخسائر.
- فترات مخصصة ومقارنة بالفترة السابقة، رسوم للمبيعات والمنتجات، وتنبيهات للمخزون والصلاحية والأرصدة.
- وضع مبسط ومتقدم وتخصيص المؤشرات والأقسام حسب المستخدم ونوع النشاط.
- خط عربي مرفق محليًا وموقع محدث بألوان الشعار الأزرق والذهبي ودليل للوحة الجديدة.
- يظل رقم الإصدار **1.1.0** بناءً على طلب صيانة الإصدار نفسه.

التحقق: اختبارات الواجهة والمتصفح وترحيلات SQLite، اختبارات Rust، بناء Windows، وفحص تثبيت وتشغيل آلي. لا يغني فحص التشغيل الآلي عن اختبار جميع العمليات يدويًا.

مصدر ملف التثبيت المحدث: [8369d68](https://github.com/Elomami1976/Dukkan/commit/8369d6817515ebb0afcd2d4973160bf064bf7428). [سجل البناء والتحقق](https://github.com/Elomami1976/Dukkan/actions/runs/40563018411). يبقى وسم الإصدار الأصلي محفوظًا؛ رابط المصدر أعلاه يحدد شفرة هذا التحديث.

## الجديد في الإصدار الأصلي

- تتبع اختياري للدفعات وتواريخ الإنتاج والصلاحية.
- صرف تلقائي للدفعة الأقرب انتهاءً وفق FEFO ومنع بيع المخزون المنتهي.
- تسجيل إتلاف المنتجات التالفة والمنتهية وإرجاع الدفعات إلى المورد مع سجل تدقيق.
- تخزين موثوق محليًا في SQLite مع حفظ المعاملة قبل عرض نجاحها في الواجهة.
- إعداد السنوات المالية وربط المبيعات والمشتريات والمصروفات والدفعات بها.
- معالج مبسط لنهاية السنة ينشئ نسخة احتياطية، يحفظ الملخص، ويبدأ السنة التالية مع استمرار المخزون والديون.
- تصفية التقارير حسب السنة المالية وتقارير خسائر المخزون ومرتجعات الموردين.
- مركز مساعدة وموقع تعريفي محدثان.

## التحديث من إصدار سابق

أنشئ نسخة احتياطية من داخل الإعدادات، أغلق Dukkan، ثم شغّل `Dukkan-Setup-1.1.0.exe`. يحتفظ التطبيق ببيانات النشاط المحلية ويرقّيها تلقائيًا.

## متطلبات النظام

- Windows 10 أو Windows 11 بنواة 64-bit.
- لا يحتاج إلى Node.js أو Rust أو اتصال دائم بالإنترنت.

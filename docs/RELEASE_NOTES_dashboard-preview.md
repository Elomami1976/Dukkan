# تحديث لوحة النشاط — مرشح للمراجعة، غير منشور

إعداد وتطوير: **طارق العمامي**.

واجهة زجاجية خفيفة مع لوحة عربية جديدة، فترات ومقارنات، مجمل ربح بالتكلفة التاريخية، مصروفات وإتلاف، أرصدة حالية، رسوم محلية، تنبيهات عملية، وضعين بسيط ومتقدم وتخصيص محلي حسب المستخدم والنشاط. خط عربي مرفق دون CDN. لا يتغير تنسيق معاملات SQLite أو النسخ الاحتياطية.

لا يعرض النظام أعمار الديون أو مواعيد سدادها لغياب بيانات الاستحقاق، ولا يضيف أوامر عمل أو بيانات نموذجية للإنتاج. الربح غير متاح عند نقص تفاصيل الفواتير التاريخية.

راجع [تعريف الحسابات وحدود التنفيذ](DASHBOARD_IMPLEMENTATION.md) و[دليل اللوحة](user-guide.html). هذا مرشح تطوير؛ لا ينشئ رابط تنزيل أو يغيّر الإصدار الرسمي المنشور. يجب إكمال تحقق البناء والمثبت قبل الإصدار الإنتاجي.

## حالة التحقق المحلي

نجح بناء الواجهة وفحص الأنواع والتنسيق البرمجي و40 اختباراً للوحدات والمعاملات و3 سيناريوهات متصفح وفحص حفظ البيانات عبر ترحيلات SQLite. تعذر إكمال ربط التطبيق الأصلي بسبب أخطاء LNK1107 وLNK2019 في رابط Visual Studio 2015. محاولة تثبيت Build Tools 2022 انتهت بالرمز 1602. لم يُنتج مثبت جديد ولم يُنشر إصدار.

لإكمال التحقق يلزم تجهيز [متطلبات Tauri على Windows](https://v2.tauri.app/start/prerequisites/)، ثم إعادة الاختبارات الأصلية وبناء المثبت وفحص تشغيله وتثبيته.

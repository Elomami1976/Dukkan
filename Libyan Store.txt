المهمة

قم ببناء تطبيق Desktop احترافي ومتكامل لإدارة الأعمال الصغيرة، المبيعات، نقطة البيع POS، المخازن، المشتريات، الموردين، العملاء، الديون، المصروفات والتقارير.

المشروع موجه بشكل أساسي إلى أصحاب الأعمال الصغيرة في ليبيا، ويجب أن يكون جاهزا للاستخدام الحقيقي، وليس Demo أو Prototype أو MVP ناقص.

الهدف النهائي هو إصدار:

v1.0.0

يستطيع المستخدم العادي تنزيله من GitHub Releases، تثبيته على جهاز Windows 10 or 11، إدخال بيانات نشاطه، ثم البدء في استخدامه مباشرة دون الحاجة إلى معرفة برمجية أو تثبيت قاعدة بيانات أو Node.js أو أي أدوات تطوير.

يجب كذلك نشر الكود المصدري بشكل منظم وموثق على GitHub.

اسم المشروع أثناء التطوير يمكن أن يكون اسما عاما قابلا للتغيير لاحقا.

1. المبادئ الأساسية

يجب الالتزام بالمبادئ التالية طوال المشروع:

التطبيق Desktop وليس Web SaaS.
التطبيق Offline First ويعمل بالكامل بدون إنترنت.
يمنع الاعتماد على أي Cloud Service لتشغيل الوظائف الأساسية.
لا يتطلب إنشاء حساب على الإنترنت.
لا يتطلب تسجيل دخول إلى خدمة خارجية.
لا توجد اشتراكات سحابية.
قاعدة البيانات محلية.
جميع بيانات النشاط محفوظة على جهاز المستخدم.
المستخدم يستطيع إنشاء Backup محلي واسترجاعه.
Windows هو النظام الأساسي المستهدف في v1.0.0.
الواجهة الأساسية باللغة العربية.
يجب دعم RTL بشكل صحيح في كامل التطبيق.
العملة الافتراضية هي الدينار الليبي LYD.
الدينار الليبي يستخدم 3 خانات عشرية.
يجب أن يستطيع صاحب النشاط تخصيص اسم البرنامج الظاهر والشعار واللون الرئيسي حسب نشاطه.
يجب أن يكون التطبيق مناسبا للمستخدم غير التقني.
يجب ألا يحتاج المستخدم النهائي إلى Terminal أو Git أو Node.js أو Rust أو SQLite أو أي أدوات تطوير.
يجب أن يكون الإصدار العام الأول منتجا متكاملا وجاهزا للعمل.

33. Restore

عند Restore:

تحقق من صحة النسخة
تحقق من Version
اعرض Confirmation واضح
لا تستبدل البيانات الحالية قبل التأكد من صلاحية النسخة
نفذ الاستعادة بأمان
أعد فتح Database إذا لزم

يجب اختبار Restore فعليا قبل إصدار v1.0.0.

35. الإلغاء والحذف

بدلا من حذفهم.

بالنسبة للفواتير:

cancelled

أي عملية إلغاء حساسة يجب أن تسجل المستخدم والوقت والسبب.

PRAGMA journal_mode = WAL;

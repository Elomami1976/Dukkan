# Dukkan — Business Manager

نظام عربي محلي لإدارة الأعمال والمبيعات ونقطة البيع والمخزون والمشتريات والديون، مصمم لأصحاب الأعمال الصغيرة في ليبيا.

المستودع الرسمي: [github.com/Elomami1976/Dukkan](https://github.com/Elomami1976/Dukkan)

## موقع المشروع

الموقع العام: [elomami1976.github.io/Dukkan](https://elomami1976.github.io/Dukkan/)

أحدث إصدار: [تنزيل Dukkan-Setup-1.0.1.exe](https://github.com/Elomami1976/Dukkan/releases/download/v1.0.1/Dukkan-Setup-1.0.1.exe) · [Release v1.0.1](https://github.com/Elomami1976/Dukkan/releases/tag/v1.0.1)

مصدر الموقع موجود في [`docs/`](docs/)، ويتم نشره عبر GitHub Pages من فرع `main`. زر التنزيل في الموقع يتحقق من وجود Windows Installer رسمي قبل تفعيله.

## حالة المشروع

الإصدار `v1.0.1` منشور وجاهز لمستخدمي Windows. تم بناء Windows Installer بصيغة NSIS واختبار تثبيته وتشغيله على بيئة Windows نظيفة قبل النشر.

## For Users

عند نشر إصدار مستقر، حمّل Windows Installer من صفحة [GitHub Releases](https://github.com/Elomami1976/Dukkan/releases)، ثبّت البرنامج ثم اتبع خطوات إعداد النشاط. لا يحتاج Dukkan إلى Node.js أو قاعدة بيانات منفصلة أو اتصال دائم بالإنترنت.

### المميزات

- نقطة بيع سريعة مع البيع النقدي والآجل وطرق الدفع المتعددة.
- إدارة المنتجات والتصنيفات والوحدات والباركود.
- مخزون قائم على سجل حركات، مع تنبيهات المخزون المنخفض والنافد.
- العملاء وكشوف الحساب والديون ودفعات العملاء.
- الموردون والمشتريات والدفعات ومرتجعات المبيعات والمشتريات.
- المصروفات والتقارير والربح التاريخي بتكلفة الشراء وقت البيع.
- نسخ احتياطي واسترجاع محلي، وصلاحيات مدير النظام والكاشير.
- واجهة عربية RTL، ودينار ليبي بثلاث خانات عشرية، ومركز مساعدة يعمل دون إنترنت.

### متطلبات النظام

Windows 10 أو Windows 11 (64-bit). البيانات تحفظ في مجلد Application Data المحلي للمستخدم.

### طريقة الاستخدام

1. أدخل بيانات النشاط واختر اللون والشعار.
2. أضف التصنيفات والمنتجات والوحدات والمخزون الافتتاحي.
3. استخدم نقطة البيع للفواتير النقدية أو الآجلة.
4. راجع الديون والمصروفات والتقارير، وأنشئ نسخاً احتياطية محلية بانتظام.

## For Developers

### الهدف من المشروع

توفير نظام مكتبي مفتوح المصدر، عربي ومحلي، يساعد الأعمال الصغيرة على إدارة البيع والمخزون والمشتريات والعملاء والموردين بدون اعتماد أساسي على الخدمات السحابية.

### التقنية

React + TypeScript + Vite في الواجهة، Tauri 2 + Rust في الطبقة الأصلية، SQLite عبر rusqlite، وZustand لإدارة الحالة. الواجهة لا تتصل بقاعدة البيانات مباشرة؛ الوصول الأصلي يمر عبر أوامر Tauri.

### التشغيل والبناء

```bash
npm install
npm run dev
npm run build
npm run tauri build
```

يتطلب بناء سطح المكتب Rust وWindows Build Tools. حزمة Windows المنشورة للمستخدمين بصيغة NSIS، ولا يحتاج المستخدم النهائي إلى أدوات التطوير.

### هيكل المشروع

- `src/App.tsx` — shell الواجهة وصفحات الميزات والتفاعلات.
- `src/store.ts` — طبقة الحالة المحلية والعمليات الأساسية.
- `src/lib/money.ts` — حسابات الدينار الليبي بوحدات minor units (1 LYD = 1000).
- `src-tauri/migrations/001_initial.sql` — مخطط SQLite مع القيود والفهارس.
- `src-tauri/src/main.rs` — تهيئة SQLite في مجلد بيانات التطبيق وتفعيل foreign keys وWAL.
- `docs/` — ملاحظات الإصدار وتصميم البيانات ودليل الاختبار.

### خارطة الطريق

- استكمال ربط العمليات المتقدمة بأوامر Tauri وخدمات Rust.
- توسيع المصادقة والصلاحيات وسجل النسخ الاحتياطية.
- إضافة الطباعة والتصدير والمرتجعات ودعم الوحدات المتعددة والـ Variants.
- تنفيذ اختبارات الوحدة والتكامل وEnd-to-End على Windows.
- استقبال ملاحظات المستخدمين وتحسين الإصدار التالي.

### العربية وRTL

الواجهة الأساسية بالعربية وتستخدم `dir="rtl"`. يجب الحفاظ على دعم RTL في الجداول والنماذج ونقطة البيع والطباعة، وعدم إضافة نصوص واجهة إنجليزية دون حاجة.

## النسخ الاحتياطي والاسترجاع

يتم حفظ بيانات النشاط محلياً. من الإعدادات اختر «إنشاء نسخة» لحفظ نسخة قابلة للاسترجاع، ولا تحذف ملف النسخة يدوياً. الاسترجاع عملية حساسة وتتطلب تأكيد المدير.
